# ChunkyCloud

ChunkyCloud is a distributed rendering platform for [Chunky](https://chunky-dev.github.io/Chunky/), the Minecraft path tracer. It allows users to render scenes across a network of community-contributed render nodes.

**[Website](https://chunkycloud.net)** · **[GitHub](https://github.com/ChunkyCloud/ChunkyCloud)** · **[Report an Issue](https://github.com/ChunkyCloud/ChunkyCloud/issues)**

## Repositories

For project-wide documentation, bug reports, and feature requests, visit the [main repository](https://github.com/ChunkyCloud/ChunkyCloud).

- [server](https://github.com/ChunkyCloud/server) – REST API, job scheduling, and credit accounting
- [website](https://github.com/ChunkyCloud/website) – Web interface
- [render-node](https://github.com/ChunkyCloud/render-node) – Distributed rendering using Chunky
- [worker-node](https://github.com/ChunkyCloud/worker-node) – Post-processing tasks
